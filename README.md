# 待办 · Daylist

一个轻量的每日待办应用：按天安排事项，支持分组、备注、重点标记、超期提醒、月历与统计。纯原生 HTML / CSS / JavaScript 实现，无构建步骤、无框架依赖，开箱即用。默认数据保存在浏览器本地，可选接入云服务实现跨设备同步。

## 功能

- **单日清单**：按日期查看、添加、勾选、重命名、移动日期、写备注、标重点；顶部汇总当天完成情况
- **克隆待办**：待办三点菜单顶部的「克隆」可按开始、结束日期批量复制，仅允许克隆到原待办之后的日期；日历左下角的「高级选项」支持从原待办的次日起，克隆至截止当天的每天、仅工作日（周一至周五）或仅休息日（周六、周日）。保留内容、分组、备注与重点标记，新待办设为未完成，原日期及更早日期不可克隆
- **分组**：在「分组」视图集中管理——新建、重命名、删除；分组删除时分组与其下待办一起进回收站
- **回收站**：待办与分组分两个分区，可逐条恢复、彻底删除或整区清空
  - 恢复待办：随分组一起删除的待办回到「未分组」，落在原日期；单独删除的待办恢复时若原分组仍在则回到该分组
  - 恢复分组：只还原一个空的分组骨架，不还原删除前组内的待办
  - 彻底删除分组：连带清除同批进回收站的待办（确认弹窗会写明数量）
- **总览与统计**：本周完成、连续完成天数、当月进度等
- **侧栏月历**：切换日期、查看每天的完成状态
- **导入 / 导出**：JSON 备份与恢复
- **跨设备同步（可选）**：接入云服务后，待办、分组与回收站保存在云端同一份记录里；每次修改自动上传，其他设备约 8 秒内自动接收。未配置云服务时自动退回纯本地模式

## 目录结构

```
index.html      页面骨架：侧栏、单日视图、总览、分组、回收站与各类弹窗
app.js          全部交互与状态（原生 JS，IIFE；云同步通过 CDN SDK）
cloud-config.js 云服务客户端配置（可选，留空即为纯本地模式）
styles.css      设计变量、布局与动效
fonts/          HarmonyOS Sans SC 字体（含 LICENSE.txt）
icon.svg        站点图标
```

## 本地运行

无需安装任何依赖，直接双击 `index.html` 即可，或在目录下起一个静态服务：

```bash
python -m http.server 8000
# 打开 http://127.0.0.1:8000/index.html
```

## 数据存储

- 默认为纯本地模式：数据保存在浏览器 `localStorage`（键名 `daylist.v2`），清空浏览器数据会丢失清单，建议定期用「导出」做 JSON 备份
- 可选云同步：在 `cloud-config.js` 中填入你自己的云服务公开配置（endpoint / publishableKey）即可启用；云端表 `daylist_records` 只有一行固定空间（`owner_id = 'personal'`），结构为 `{ version, todos, groups, trash: { todos, groups } }`
- 多台设备同时离线修改时，以最后一次上传到云端的整份清单为准
